# Выпуск 4 — IS-IS и BGP

Материалы к выпуску о IGP IS-IS и BGP в сети Интернет-провайдера.

## Видео

## В этом выпуске

- базовые принципы IS-IS;
- IS-IS на Juniper;
- основы BGP;
- eBGP с внешним оператором;
- default route по eBGP;
- анонс собственных маршрутов;
- фильтрация BGP-маршрутов;
- BGP communities;
- iBGP внутри сети оператора;
- BGP Route Reflector;
- next-hop self;
- iBGP на Juniper, Huawei, Nokia и Cisco;
- административная дистанция BGP;
- ECMP для BGP на Nokia.
