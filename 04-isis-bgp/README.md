# Выпуск 4 — IS-IS и BGP в сети Интернет-провайдера

Материалы к четвёртому выпуску серии «Построение сети Интернет-провайдера в EVE-NG».

## Видео

[Смотреть выпуск 4 на YouTube](https://youtu.be/C8l0weSKNxg)

## В этом выпуске

- базовые принципы IS-IS;
- настройка IS-IS на Juniper;
- основы BGP;
- настройка eBGP с внешним оператором;
- получение default route по eBGP;
- анонс собственных маршрутов во внешний оператор;
- фильтрация BGP-маршрутов;
- BGP communities;
- построение iBGP внутри сети оператора;
- BGP Route Reflector;
- next-hop self;
- настройка iBGP на Juniper, Huawei, Nokia и Cisco;
- изменение административной дистанции BGP;
- ECMP для BGP на Nokia.
