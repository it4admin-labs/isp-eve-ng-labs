# Juniper vMX — метафайлы

Материалы Juniper, используемые в лаборатории первого выпуска.

## Juniper vMX версии 18

- [`metadata-usb-re0.img`](./metadata-usb-re0.img) — метафайл для RE0.
- [`metadata-usb-re1.img`](./metadata-usb-re1.img) — метафайл для RE1.
- [`metadata-usb-fpc0.img`](./metadata-usb-fpc0.img) — метафайл для FPC0.
- [`metadata-usb-fpc1.img`](./metadata-usb-fpc1.img) — метафайл для FPC1.
- [`metadata-usb-service-pic-2g.img`](./metadata-usb-service-pic-2g.img) — метафайл для активации MS-MPC.

Эти файлы предназначены для подготовки конфигурации виртуального Juniper vMX версии 18 в EVE-NG.
