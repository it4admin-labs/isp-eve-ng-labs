# Juniper

Материалы и ПО Juniper, используемые в лаборатории первого выпуска.

## Метафайлы Juniper vMX версии 18

- `metadata-usb-re0.img` — метафайл для RE0 для Juniper vMX версии 18.
- `metadata-usb-re1.img` — метафайл для RE1 для Juniper vMX версии 18.
- `metadata-usb-fpc0.img` — метафайл FPC0 для Juniper vMX версии 18.
- `metadata-usb-fpc1.img` — метафайл FPC1 для Juniper vMX версии 18.
- `metadata-usb-service-pic-2g.img` — метафайл для активации MS-MPC для Juniper vMX версии 18.
