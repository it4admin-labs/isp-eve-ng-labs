# Выпуск 1 — EVE-NG и виртуальное оборудование

Материалы к первому выпуску серии «Построение сети Интернет-провайдера в EVE-NG».

## Видео

[Смотреть выпуск 1 на YouTube](https://youtu.be/KsVRNM9Hk0k)

## В этом выпуске

- обзор виртуальной сети Интернет-провайдера в EVE-NG;
- BRAS / BNG;
- ishare2;
- Juniper VMX;
- два Routing Engine и два FPC;
- эмуляция MS-MPC и NAT;
- Nokia VSR;
- Huawei CE6800;
- ZRAM и оптимизация памяти Linux-сервера.

## Материалы

- [Кастомные шаблоны EVE-NG](./custom-templates/) — шаблоны виртуального сетевого оборудования.
- [Топология EVE-NG](./topology/) — готовый файл лаборатории `ISP_NET.unl` и список необходимых образов.
- [Схема лаборатории](./diagrams/) — графическая схема виртуальной сети.
- [Juniper vMX](./software/juniper/) — метафайлы для Juniper vMX версии 18.

## Быстрый старт

1. Установите необходимые образы EVE-NG и кастомные шаблоны.
2. Загрузите файл [`ISP_NET.unl`](./topology/ISP_NET.unl) в EVE-NG.
3. При необходимости используйте [схему лаборатории](./diagrams/) как справочник по топологии.
4. Для Juniper vMX версии 18 используйте [метафайлы](./software/juniper/).

Подробнее о требуемых образах и составе лаборатории: [Топология EVE-NG](./topology/).
