# Выпуск 1 — EVE-NG и виртуальное оборудование

Материалы к выпуску о подготовке виртуальной лаборатории сети Интернет-провайдера в EVE-NG.

## Видео

[Смотреть выпуск 1 на YouTube](https://www.youtube.com/playlist?list=PLoSvnAe9cgLDNtF89-A1s0qLyCRjXEok_)

## В этом выпуске

- обзор виртуальной сети Интернет-провайдера в EVE-NG;
- BRAS / BNG;
- ishare2;
- Juniper VMX;
- два Routing Engine и два FPC;
- эмуляция MS-MPC и NAT;
- Nokia VSR;
- Huawei CE6800;
- ZRAM и оптимизация памяти Linux-сервера.

## Каталоги

- `custom-templates/` — шаблоны оборудования для EVE-NG;
- `topology/` — топологии EVE-NG и схемы;
- `diagrams/` — сетевые схемы;
- `notes/` — дополнительные заметки.
- `software/juniper/` - метафайлы для Juniper vMX
