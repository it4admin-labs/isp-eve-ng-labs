# Выпуск 3 — OSPF и ECMP в сети Интернет-провайдера

Материалы к третьему выпуску серии «Построение сети Интернет-провайдера в EVE-NG».

## Видео

[Смотреть выпуск 3 на YouTube](https://youtu.be/4EPujocuo64)

## В этом выпуске

- базовые принципы IGP и протоколов Link-State;
- настройка OSPF на Juniper;
- настройка OSPF на Huawei;
- настройка OSPF на Nokia;
- настройка OSPF на Cisco IOS XR и IOS XE;
- решение проблем с несоответствием MTU;
- диагностика и debug OSPF;
- балансировка трафика по равноценным путям ECMP;
- настройка ECMP на Juniper и Nokia;
- проверка работы ECMP на Huawei и Cisco;
- административные дистанции и приоритеты протоколов маршрутизации.
