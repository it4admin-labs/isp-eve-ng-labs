# Выпуск 5.1 — Snort 3, DPI и Inline IPS

Материалы к выпуску об установке и настройке Snort 3 в EVE-NG для DPI и прозрачной inline-фильтрации.

## Видео

[Смотреть выпуск 5.1 на YouTube](https://youtu.be/wskNBQyP520)

## В этом выпуске

- установка Debian 13 в EVE-NG;
- компиляция и установка Snort 3 из исходного кода;
- установка и проверка LibDAQ;
- настройка Linux-интерфейсов для прозрачной inline-схемы;
- запуск Snort 3 в режиме Inline IPS через AFPacket;
- подключение собственных правил;
- блокировка ICMP;
- обнаружение и блокировка HTTP-запросов по имени ресурса;
- отправка собственной страницы-заглушки при блокировке HTTP;
- проверка работы Snort 3 в тестовой сети оператора.

## Как работает лаборатория

Snort 3 устанавливается на Debian 13 и работает как прозрачный inline-фильтр между двумя сетевыми интерфейсами Linux. Трафик проходит через пару интерфейсов `eth1:eth2`, а правила определяют, какой трафик разрешить, отклонить или заблокировать.

В лаборатории используется `react` для HTTP-блокировки: при совпадении правила Snort отправляет клиенту страницу-заглушку и завершает сессию. Для ICMP используется `reject`.

> Правило блокировки HTTP в этой лаборатории рассчитано на незашифрованный HTTP-трафик. Имя ресурса в HTTPS-сеансе зашифровано, поэтому это конкретное правило не предназначено для блокировки HTTPS по имени сайта.

> В репозитории опубликованы конфигурация, локальные правила и HTML-страница. Образы Debian и исходные компоненты Snort/LibDAQ в репозиторий не входят.
