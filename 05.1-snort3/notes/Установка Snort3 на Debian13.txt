1. Установка зависимостей:
apt install -y build-essential cmake flex g++ bison git libpcap-dev libpcre2-dev libluajit-5.1-dev 
apt install -y libssl-dev zlib1g-dev liblzma-dev libpkgconf-dev pkg-config libhwloc-dev libdumbnet-dev
apt install -y libsqlite3-dev ethtool net-tools libfl-dev flex libgoogle-perftools-dev

2. Установка библиотеки libdaq:
cd /tmp
git clone https://github.com/snort3/libdaq.git
cd libdaq
./bootstrap
./configure
make -j$(nproc)
sudo make install

3. Установка Snort3:
cd /tmp
git clone https://github.com/snort3/snort3.git
cd snort3
./configure_cmake.sh --prefix=/usr/local --enable-tcmalloc
cd build
make -j$(nproc)
sudo make install

sudo ldconfig


4. Настройка сетевых интерфейсов Linux:
/etc/network/interfaces

auto eth1
allow-hotplug eth1
        iface eth1 inet manual
        up ifconfig eth1 promisc up
        up ifconfig eth1 mtu 9000 up
        up /usr/sbin/ethtool -K eth1 gro off lro off

auto eth2
allow-hotplug eth2
        iface eth2 inet manual
        up ifconfig eth2 promisc up
        up ifconfig eth2 mtu 9000 up
        up /usr/sbin/ethtool -K eth2 gro off lro off


5. Создание сервиса Systemd для зупуска Snort3:
nano /etc/systemd/system/snort.service

------------------

[Unit]
Description=Snort Daemon
After=syslog.target network.target

[Service]
Type=simple
ExecStart=/usr/local/bin/snort -Q -c /usr/local/etc/snort/snort.lua -l /var/log/snort/ --daq afpacket -i eth1:eth2
ExecStop=/bin/kill -9 $MAINPID

[Install]
WantedBy=multi-user.target
-----------------

Поочередно выполнить команды:
systemctl daemon-reload
systemctl enable snort.service
systemctl start snort.service
