# Конфигурация Snort 3

Файлы конфигурации и правила для выпуска 5.1 «Snort 3, DPI и Inline IPS».

## Файлы

| Файл | Назначение |
|---|---|
| [`snort.lua`](./snort.lua) | Основная конфигурация Snort 3: HOME_NET, инспекторы, binder, IPS, локальные правила, `react`, `reject` и журналирование. |
| [`local_rules`](./local_rules) | Локальные правила лаборатории: блокировка ICMP и HTTP по имени ресурса. |
| [`my_block_page.html`](./my_block_page.html) | Собственная HTML-страница, которую Snort использует как ответ при срабатывании `react`. |

## Куда устанавливать

Для варианта запуска из инструкции рекомендуется следующая структура:

```text
/usr/local/etc/snort/
├── snort.lua
├── local_rules
└── my_block_page.html
```

Файл `snort.lua` подключает `local_rules`, а блокирующее HTTP-правило использует `my_block_page.html`.

## Что настроено в snort.lua

В конфигурации уже включены необходимые для выпуска параметры:

- `HOME_NET` содержит тестовые сети лаборатории;
- `EXTERNAL_NET` задан как все сети за пределами `HOME_NET`;
- включён HTTP inspector;
- встроенные IPS-правила отключены через `enable_builtin_rules = false`;
- подключается файл `local_rules`;
- настроен `react` с использованием `my_block_page.html`;
- настроен `reject`;
- включён `alert_fast`.

Перед использованием конфигурации в другой лаборатории проверьте прежде всего `HOME_NET`, имена сетевых интерфейсов и пути к файлам.
