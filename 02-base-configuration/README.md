# Выпуск 2 — Базовая настройка оборудования

Материалы к выпуску о базовой настройке сетевого оборудования перед построением IGP, BGP и MPLS.

## В этом выпуске

- базовая настройка Juniper;
- базовая настройка Huawei;
- базовая настройка Nokia;
- базовая настройка Cisco IOS XR и IOS XE;
- физические интерфейсы;
- LACP / LAG;
- Loopback;
- LLDP.

## Каталоги

- `configs/` — конфигурации;
- `topology/` — топологии EVE-NG и схемы;
- `diagrams/` — сетевые схемы;
- `notes/` — дополнительные заметки.
