# Выпуск 2 — Базовая настройка оборудования

Материалы ко второму выпуску серии «Построение сети Интернет-провайдера в EVE-NG».

## Видео

[Смотреть выпуск 2 на YouTube](https://youtu.be/BDmeO4KkybM)

## В этом выпуске

- базовая настройка Juniper;
- базовая настройка Huawei;
- базовая настройка Nokia;
- базовая настройка Cisco IOS XR и IOS XE;
- физические интерфейсы;
- LACP / LAG;
- Loopback;
- LLDP.
