## О проекте

Серия последовательно строит сеть Интернет-провайдера в виртуальной лаборатории EVE-NG. Технологии IP/MPLS операторских сетей рассматриваются в контексте единого практического проекта.

Материалы предназначены для специалистов, имеющих базовые знания компьютерных сетей.
