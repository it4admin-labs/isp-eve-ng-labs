# Выпуск 8 — BRAS Juniper и FreeRADIUS

Материалы к восьмому выпуску серии «Построение сети Интернет-провайдера в EVE-NG».

## В этом выпуске

- подключение BRAS Juniper к FreeRADIUS;
- настройка RADIUS и AAA для IPoE-абонентов;
- формирование логина абонента по DHCP Option 82;
- настройка DHCP Local Server и IPoE-сессий;
- создание динамических абонентских профилей;
- выдача публичных IP-адресов через RADIUS;
- настройка скоростных профилей и полисеров;
- финансовая блокировка абонента;
- HTTP Redirect на информационную страницу;
- доступ к разрешённым ресурсам при финансовой блокировке;
- RADIUS CoA (Change of Authorization);
- динамическая активация, снятие и смена сервисных профилей без переподключения;
- проверка доступа абонента в Интернет.

## Состав лаборатории

В выпуске используются:

- **BRAS-2** — Juniper под Junos 18.4R3-S5.4, выполняющий функции BRAS/BNG для IPoE-абонентов;
- **NAT-1** — Juniper, через который L2-сервисы абонентов доставляются к BRAS-2;
- **FreeRADIUS** — сервер AAA, хранящий параметры абонентов и сервисные атрибуты.

## Лабораторный сценарий

В выпуске 7 аналогичный сценарий был реализован на BRAS Cisco IOS XR. В выпуске 8 абонентские сервисы переносим на Juniper.

Клиентский трафик через L2-сервисы приходит на BRAS-2. На NAT-1 для этого сценария L2C к BRAS-2 переведены на агрегированный интерфейс `ae5`; используются VC 3201–3204.

На BRAS-2 включён subscriber management. DHCP Local Server принимает запросы абонентов через динамические demux-интерфейсы, а имя пользователя для RADIUS формируется из DHCP Option 82 — Circuit-ID и Remote-ID.

FreeRADIUS используется для авторизации абонентов и передачи параметров сервиса. Через RADIUS абоненту могут назначаться адресный пул, постоянный публичный IP и динамический сервис ограничения скорости.

Для изменения активной сессии используется RADIUS CoA. В лаборатории показаны активация и снятие профиля финансовой блокировки `REDIRECT_NOPAY`, а также смена скоростного профиля `RATELIMIT` без переподключения абонента.

На этом этапе абоненты выходят в Интернет с публичными IP-адресами. NAT и CGNAT будут рассмотрены в следующих выпусках.
