## Назначение

Основная часть выпуска посвящена реализации BRAS/BNG на Juniper и его интеграции с FreeRADIUS.

В конфигурациях будут представлены:

- RADIUS authentication и accounting;
- IPoE subscriber sessions;
- динамические абонентские профили;
- параметры, получаемые от FreeRADIUS;
- полисеры скорости;
- профиль финансовой блокировки;
- HTTP redirect и доступ к разрешённым ресурсам;
- dynamic authorization / RADIUS CoA.

## Лабораторный сценарий

Абонентский трафик завершается на Juniper BRAS. FreeRADIUS используется для авторизации абонентов и выдачи параметров сервисного профиля.

После загрузки реальных конфигураций этот README будет дополнен точными именами файлов, моделями оборудования, ролями узлов и кратким описанием ключевых настроек.

## Учетные данные лаборатории

В опубликованных конфигурациях могут использоваться тестовые учётные данные и shared secrets, предназначенные только для виртуальной лаборатории.

> Не используйте их в производственной сети. Перед применением конфигураций замените пароли, RADIUS shared secrets, IP-адреса и другие параметры доступа.
