## В этом выпуске

- установка и базовая настройка FreeRADIUS;
- подключение BRAS Cisco IOS XR к RADIUS-серверу;
- настройка AAA для абонентских сессий;
- создание профилей пользователей в FreeRADIUS;
- передача параметров сервиса с RADIUS на BRAS;
- настройка полисеров и ограничение скорости абонентов;
- финансовая блокировка абонента;
- перенаправление заблокированного абонента на информационную страницу;
- доступ к разрешённым ресурсам из профиля финансовой блокировки;
- использование RADIUS CoA (Change of Authorization);
- динамическая смена профиля абонента с помощью CoA;
- проверка доступа абонента с публичным IP-адресом в Интернет.

## Лабораторный сценарий

В предыдущем выпуске клиентский трафик был доставлен через MPLS L2 VPN до BRAS. В этом выпуске BRAS Cisco IOS XR подключается к FreeRADIUS и начинает использовать RADIUS для авторизации абонентов и получения параметров их сервисных профилей.

FreeRADIUS определяет параметры обслуживания абонента, а BRAS применяет полученные настройки к пользовательской сессии. В лаборатории рассматриваются обычный профиль доступа, ограничение скорости с помощью полисеров и профиль финансовой блокировки с перенаправлением пользователя на информационную страницу.

Для изменения параметров уже активной абонентской сессии используется RADIUS CoA (Change of Authorization), что позволяет менять профиль пользователя без полного переподключения.

На этом этапе абоненты используют публичные IP-адреса. NAT и CGNAT в данном выпуске не настраиваются.
