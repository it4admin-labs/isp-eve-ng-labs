# Выпуск 7 — FreeRADIUS и BRAS Cisco IOS XR

Материалы к седьмому выпуску серии «Построение сети Интернет-провайдера в EVE-NG».

## Видео

## В этом выпуске

- установка и базовая настройка FreeRADIUS;
- подключение BRAS Cisco IOS XR к RADIUS-серверу;
- настройка AAA для абонентских сессий;
- создание профилей пользователей в FreeRADIUS;
- передача параметров сервиса с RADIUS на BRAS;
- настройка полисеров и ограничение скорости абонентов;
- финансовая блокировка абонента;
- перенаправление заблокированного абонента на информационную страницу;
- доступ к разрешённым ресурсам из профиля финансовой блокировки;
- использование RADIUS CoA (Change of Authorization);
- динамическая смена профиля абонента с помощью CoA;
- проверка доступа абонента с публичным IP-адресом в Интернет.

## Состав лаборатории

В выпуске используются:

- **BRAS-1** — Cisco IOS XR, выполняет функции BRAS/BNG для IPoE-абонентов;
- **FreeRADIUS** — сервер AAA, хранящий параметры абонентских профилей;
- **AR-1** — Cisco CSR1000v;
- **NOC-SW-1** — коммутатор технологического сегмента, к которому подключён сервер FreeRADIUS.

## Лабораторный сценарий

Клиентский трафик, доставленный до BRAS через MPLS L2 VPN, завершается на Cisco IOS XR. BRAS формирует RADIUS-запрос, получает параметры абонента из FreeRADIUS и применяет их к IPoE-сессии.

Через RADIUS задаются параметры пользовательского профиля, IP-адрес, DHCP-класс и сервисы BRAS. В лаборатории используются динамические шаблоны полисеров, профиль финансовой блокировки с HTTP redirect и RADIUS CoA для изменения сервисов уже активной сессии.

На этом этапе абоненты выходят в Интернет с публичными IP-адресами. NAT и CGNAT будут рассмотрены в следующих выпусках.
