## Назначение

Основная часть выпуска сосредоточена на связке FreeRADIUS и BRAS Cisco IOS XR.

На BRAS настроены:

- RADIUS authentication и accounting;
- dynamic authorization / CoA;
- IPoE subscriber sessions;
- DHCP-классы для абонентов;
- динамические сервисные шаблоны;
- полисеры скорости;
- профиль финансовой блокировки;
- HTTP redirect и доступ к разрешённым ресурсам.

Каталог [`freeradius/`](./freeradius/) содержит конфигурацию RADIUS-сервера, пользовательские профили и отдельную инструкцию по установке и CoA.

## Лабораторный сценарий

FreeRADIUS доступен BRAS через отдельный VRF `RADIUS-IPoE`. BRAS отправляет authentication и accounting на сервер `172.31.0.100`, а сервер идентифицирует BRAS как RADIUS client по адресу `198.18.0.3`.

Параметры абонента передаются через стандартные RADIUS-атрибуты и Cisco AVPair. Для активных сессий изменение сервисов выполняется с помощью CoA.

## Учетные данные лаборатории

В опубликованных конфигурациях используются тестовые учётные данные и shared secrets, предназначенные только для виртуальной лаборатории.

> Не используйте их в производственной сети. Перед применением конфигураций замените пароли, RADIUS shared secrets, IP-адреса и другие параметры доступа.
