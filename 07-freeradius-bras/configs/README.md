# Конфигурации и настройки

Файлы конфигураций для выпуска «FreeRADIUS и BRAS Cisco IOS XR — Выпуск 7».

## Содержимое

Конфигурации будут добавлены после публикации материалов выпуска.

Планируется разместить здесь настройки, использованные в лаборатории, включая:

- FreeRADIUS;
- BRAS Cisco IOS XR;
- профили абонентов;
- параметры полисеров;
- профиль финансовой блокировки и redirect;
- настройки доступа к разрешённым ресурсам;
- RADIUS CoA (Change of Authorization);
- другие конфигурации узлов, непосредственно участвующих в сценариях выпуска.

После загрузки файлов этот README будет дополнен таблицей с именами файлов, типами оборудования и назначением каждой конфигурации.

## Назначение

Материалы предназначены для практического воспроизведения связки FreeRADIUS и BRAS Cisco IOS XR, настройки абонентских сервисных профилей и управления активными сессиями через RADIUS CoA.

## Учетные данные лаборатории

В опубликованных конфигурациях могут использоваться тестовые учётные данные, предназначенные только для виртуальной лаборатории.

> Не используйте эти учётные данные в производственной сети. Перед применением конфигураций вне лаборатории замените пароли, shared secrets, IP-адреса и другие параметры доступа.
